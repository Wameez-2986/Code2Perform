# Code2Perform

Digital Design, Engineering & Long-Term Growth.

An independent digital agency delivering high-performance business websites, mobile applications, custom software platforms, and business automation.

## Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 with custom Satoshi editorial design system
- **Icons**: Lucide React

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production Build

```bash
npm run build
npm run start
```
